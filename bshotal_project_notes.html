6. Staging & Client Ownership Transfer Process

  1. Staging Deployment (Developer Account):
    The code is pushed to your private GitHub repo and imported into your personal Vercel and Render accounts. A preview link (e.g., bshotel.vercel.app) is provided for the client to review and test.
  2. Client Approval & Milestone Payment:
    The client tests room booking, restaurant ordering, menu administration, and reports. Once satisfied, the final milestone invoice is cleared.
  3. Two-Minute Zero-Downtime Handoff:
    • Vercel: In Project Settings → Click Transfer Project → Enter client's Vercel username/email. Instant migration.
    • Database: In Supabase/MongoDB → Organization Settings → Invite client as Owner → Remove developer seat.
    • Domain DNS: Add CNAME/A records on the client's Hostinger/Namecheap dashboard pointing to Vercel.
